# YumeRobo

A static site for keeping a record of some releases.

## Tech Stack

- **Framework**: [Svelte 5](https://svelte.dev/) and [SvelteKit 2](https://svelte.dev/docs/kit/) with TypeScript
- **Styling**: Vanilla CSS with CSS Custom Properties
- **Viewer**: Vendored browser-native ESM build from [yacomp-web](https://github.com/Miralia/yacomp-web)
- **Build & Tooling**: [Vite](https://vite.dev/) and [Bun](https://bun.sh/)
- **Deployment**: Prerendered static output on [Cloudflare Pages](https://pages.cloudflare.com/)
